ПРОВЕРКА ТЕЛЕМЕТРИИ КУПОЛА В ЛОКАЛЬНОЙ СЕТИ

1. Подключите компьютер к локальной сети Купола.
2. Распакуйте комплект целиком. Нужен Python 3.11 или новее.
3. Если есть Dome_RAG-main.zip с ключом команды 4, положите его рядом
   с check_dome.py. Иначе программа запросит ключ скрытым вводом.
4. Дважды нажмите check_dome.cmd.

По умолчанию проверяется ws://192.168.8.126:8765. Телеметрия собирается
12 секунд после подключения; общий сетевой таймаут — 35 секунд.
Окно покажет результат и останется открытым. Скрипт только читает данные;
управляющие команды оборудованию не отправляются.

Для другого адреса откройте терминал в папке комплекта и выполните:

  .\check_dome.cmd --address 192.168.8.126:8765
  .\check_dome.cmd --address ws://192.168.8.126:8765 --duration 30
  .\check_dome.cmd --address wss://janus-server.a.2na.am:443

Ключ DOME_KEY из переменных окружения имеет приоритет. Другой архив
и команду можно выбрать аргументами --keys-archive и --team.
Не помещайте ключ в адрес сервера или текст команды.

Результаты сохраняются в output/dome_check/<дата-время>/:

  report.txt             — итог проверки для чтения человеком;
  report.json            — итог в JSON;
  parameters.txt         — доступные параметры;
  telemetry.jsonl        — полученные сообщения телеметрии;
  latest_telemetry.json  — последний снимок;
  catalog.json           — каталог оборудования и команд.

Последний снимок и каталог создаются только после получения этих данных.
При ошибке подключения отчёт всё равно сохраняется. Доступность TCP-порта
не считается успехом: нужны авторизация команды 4 и кадр телеметрии.

Код завершения: 0 — телеметрия получена; 1 — проверка не удалась.
Код 2 означает ошибку запуска или аргументов. Таймаут может означать
неверный адрес, отсутствие локальной сети или недоступность сервера.

В комплект dome_connection_check.zip включена зависимость websockets 17.3
в каталоге _vendor с лицензией. Для этого комплекта интернет не нужен;
установленный Python 3.11 или новее всё равно необходим.
При отсутствии _vendor launcher установит websockets из интернета.
При первом запуске check_dome.cmd создаёт локальное окружение .venv.

Подробные параметры: python check_dome.py --help
