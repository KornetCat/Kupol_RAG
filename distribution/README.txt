КУПОЛ 0.4.0 — ГОТОВЫЕ СБОРКИ

kupol_windows_x64_0.4.0.zip — переносимая сборка Windows x64 с Python и всеми зависимостями.
kupol_rag_agent_0.4.0.zip — исходники, знания RAG, тесты и скрипты сборки.

Скачайте нужный ZIP, распакуйте целиком и запустите start_web.cmd.
В переносимой сборке устанавливать Python или pip не требуется.
Добавьте свой Dome_RAG-main.zip с ключами команды 4 рядом с лаунчером либо введите ключи в интерфейсе.
Ключей и пользовательских журналов в сборках нет.
Для DeepSeek нужен интернет. Адрес Купола задаётся в интерфейсе.

Три критерия потоков задаются для конкретного объекта. Числовых нормативов в предоставленных документах нет.
Пример 60% / 200 м3/ч / 2 л/мин — только предварительная настройка виртуального стенда; 200 м3/ч не подтверждены здоровой выборкой FRESH_AIR100.
Для реального объекта используйте согласованные минимумы. Аппаратные защиты не отключаются.

Контрольные суммы: RELEASE_SHA256.txt. Результаты испытаний: test_report_latest.txt и docs/VALIDATION_RESULTS.json в корне проекта.
